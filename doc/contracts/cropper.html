cropper — design contract

theme: marble zk-version: 10.2.1-jakarta tier: T3 (wrapper-only) closest-sibling: none (novel media wrapper)

T3 component: .z-cropper and .z-cropper-toolbar (+ ul/li/a) are the free design surface. The Jcrop library injects .z-cropper-holder, .z-cropper-area, .z-cropper-handle, .jcrop-dragbar, and related elements at runtime but ships no stylesheet — the theme MUST reproduce the upstream codegen geometry for them verbatim (structural-required; only decorative values are theme choices). .z-cropper-canvas does NOT exist in the live DOM.

T3 Boundary Reference

Restyle freely (theme design surface):
.z-cropper — root wrapper
.z-cropper-toolbar — floating action toolbar
.z-cropper-toolbar > ul, li, a — action items

Structural-required (Jcrop-injected, but Jcrop ships NO stylesheet — theme MUST reproduce upstream codegen geometry; decorative values only may diverge):
.z-cropper-holder — Jcrop image container (never set width/height — JS owns)
.z-cropper-area — selection overlay (outline 1px solid white, cursor move)
.z-cropper-vline, .z-cropper-hline — 1px guide lines
.z-cropper-tracker — full-size mouse-event capture overlay
.z-cropper-handle — 6×6 handles + 8 per-ordinal transforms
.jcrop-dragbar — 6px resize bars (retains jcrop- prefix despite baseClass override)

Forbidden:
.z-cropper-canvas — DOES NOT EXIST (absent from live DOM — do not reference)
