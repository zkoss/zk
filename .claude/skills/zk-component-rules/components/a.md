# a (link)

An anchor/hyperlink component that renders as a styled `<a>` element.

## DOM structure

```
a.z-a                              (root <a> element)
```

## State classes and pseudo-classes

- `:hover` — hover state
- `:visited` — visited link
- `[disabled]` — disabled attribute (note: `<a>` elements don't natively support `disabled` — ZK adds pointer-events: none via CSS when disabled is set)
