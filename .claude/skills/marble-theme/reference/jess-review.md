# Replying to the designer's review (Jess)

Read this before answering a screenshot from the designer, starting a verification batch for her
issues, or touching a meeting record.

1. **Reproduce her screenshot, not yours.** Open the designer's original image first and reproduce
   it with the same page, URL, UI steps, viewport, DPR and crop. If her state does not show the
   fix, add a second screenshot that does. A screenshot taken for measuring is internal evidence,
   not the answer sent to her.
2. **"Decide the verification method first" means the batch about to start**, not the whole
   backlog. When the scope is unclear, take the narrower reading, or ask before dispatching an
   agent.
3. **Meeting records are read-only.** Put the evaluation in a new `doc/` file that cites the
   record's path and the issue ID. Never write it into the record itself.
